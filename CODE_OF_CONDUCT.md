# Code of Conduct

mini-git has adopted the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Its full text applies to everyone who takes part in
the project: in issues, pull requests, reviews and every other project space,
and when someone represents the project in public.

## In short

mini-git is a place to learn, so many people here are trying something new.
We expect everyone to:

- be kind, patient and welcoming, especially to beginners: there are no silly
  questions;
- respect different opinions, experiences and ways of working;
- give feedback about the code, never about the person, and accept feedback
  gracefully;
- take responsibility for mistakes, apologize to anyone affected, and learn
  from them;
- focus on what is best for the whole community.

These are not acceptable:

- harassment, insults, or personal or political attacks;
- sexualized language or images, or unwelcome sexual attention;
- trolling, or deliberately derailing a discussion;
- publishing someone's private information, such as a home or email address,
  without their explicit permission;
- any other behavior that would reasonably be seen as inappropriate in a
  professional setting.

## Reporting

If you experience or see behavior that breaks this code of conduct, please
report it privately to the maintainer, @MITRAKER, through GitHub, using the
contact options on [@MITRAKER's GitHub profile](https://github.com/MITRAKER).
Please do not report conduct problems in a public issue.

If the problem involves the maintainer, or you would rather not contact them,
report it to GitHub instead: use **Report content** in the **...** menu of
any comment, issue or pull request. GitHub's guide
[Reporting abuse or spam](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
explains how.

Every report is reviewed promptly and fairly. The maintainer keeps the
identity of the person who reported it private.

## Enforcement

The maintainer enforces this code of conduct and may remove, edit or reject
comments, commits, code, issues and other contributions that break it.
Consequences follow the Contributor Covenant's enforcement guidelines: a
private correction, a warning, a temporary ban or a permanent ban, depending
on how serious the behavior was and whether it was repeated.
